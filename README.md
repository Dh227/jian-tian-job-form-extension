# 简填 · 网申资料助手

一个本地优先的 Chrome / Microsoft Edge 扩展。用户保存一次基础资料，打开企业网申表后即可预览并一键填写；插件不会自动提交申请。

## 已实现功能

- 首次安装自动打开资料页，资料保存在当前浏览器。
- 识别文本框、日期、月份、下拉框、单选框、复选框和附件控件。
- 支持姓名、电话、邮箱、城市、求职意向、最高学历、个人链接等中英文字段别名。
- 填写时触发 `input`、`change`、`blur` 事件，兼容常见动态表单。
- 默认保留网页中已有内容，可由用户主动选择覆盖。
- 填写前预览并隐藏手机号、邮箱等信息的部分字符。
- 显示可填写、待确认、资料缺失和未识别字段数量。
- 对低置信度或敏感字段要求用户单独确认。
- 附件控件提示手动选择，不绕过浏览器文件安全限制。
- 支持撤销本次填写。
- 拦截密码、验证码、银行卡、社保、公积金、法律声明、背景调查和竞业授权等字段。
- 只使用 `activeTab` 临时权限，不申请读取所有网站。

## 安装

### Chrome

1. 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 浏览器会打开“默认资料”页面，填写姓名、手机号、邮箱等信息并保存。

### Microsoft Edge

1. 地址栏打开 `edge://extensions`。
2. 打开左侧“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目目录。

## 使用

1. 进入企业招聘官网的申请表单页面。
2. 点击浏览器工具栏中的“简填”。
3. 查看网站支持程度、识别数量和本次填写预览。
4. 如需填写橙色标记字段，核对后勾选确认项。
5. 点击“一键填写”。
6. 在网页中逐项检查，手动上传简历附件并自行提交申请。

如果网页已经有内容，插件默认不会覆盖。填写错误时，可在弹窗关闭前点击“撤销”。

## 安全边界

- 不自动提交申请，不处理验证码，不绕过登录或网站限制。
- 不填写隐私授权、背景调查、竞业限制和真实性承诺。
- 首版不保存身份证号、银行卡、社保、公积金和密码。
- 没有账号系统、云同步、统计 SDK 或远程接口。

详细说明见 [PRIVACY.md](./PRIVACY.md)。

## 本地验证

```bash
npm run check
npm test
```

浏览器级测试需要 Python Playwright：

```bash
python3 -m pip install -r tests/requirements.txt
python3 -m playwright install chromium
python3 tests/browser_test.py
```

测试覆盖字段别名、安全拦截、表单识别、动态新增字段、事件触发、已有内容保护、下拉框填写、附件提示、撤销、资料保存和弹窗结果反馈。

## 当前范围

当前版本为 `0.1.0`，聚焦单用户、单份默认资料和基础信息填写。多份资料、网站专用适配规则、填写历史、云同步和 AI 开放题不在首版范围内。
