# 简填 · 网申资料助手

一个本地优先的 Chrome / Microsoft Edge 扩展。它可以从母版简历识别常用网申资料、保存岗位网页与截图，并为每个岗位生成可复制给 Codex 的定制简历提示词。扩展不会自动提交申请，也不会调用远程 AI。

## 0.2 功能

- 上传文本型 PDF 或 `.docx`，在本地提取姓名、联系方式、求职方向、教育、能力、实习 / 工作、项目和证书。
- 导入前预览识别结果；新字段可直接同步，冲突字段由用户决定是否覆盖，无法识别的内容可以补充后重新识别。
- 原始母版文件、结构化简历和岗位截图保存在浏览器本机，可下载或删除。
- 在岗位详情页点击“保存当前岗位”，优先读取页面的 `JobPosting` 结构化数据，并保存当前可见区域截图。
- 管理多个岗位档案，包括公司、岗位、地点、薪资、JD、任职要求、备注、来源和投递状态。
- 为岗位生成 Codex 提示词，要求基于用户配置的本地简历工作区输出 DOCX、PDF 和修改说明，并禁止虚构经历。
- 保留 0.1 的字段识别、填写预览、一键填写、低置信度确认、已有值保护和撤销能力。

## 安装

### Chrome

1. 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后的本项目目录。
5. 首次安装会打开“求职资料工作台”。

### Microsoft Edge

1. 地址栏打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目目录。

## 使用流程

### 1. 建立母版简历

1. 在资料工作台打开“母版简历”。
2. 上传文本型 PDF 或 Word `.docx`，文件不得超过 20 MB。
3. 检查识别预览；冲突字段不会静默覆盖已有资料。
4. 在提取文本中补充缺失章节并点击“重新识别”。
5. 勾选需要同步的基本资料，保存母版。

扫描版图片 PDF 没有文本层，当前版本不做 OCR。原文件仍可作为母版保存，用户可以在提取文本区域手工补充。

### 2. 保存岗位

1. 打开企业招聘官网或招聘平台的岗位详情页。
2. 点击浏览器工具栏中的“简填”。
3. 点击“保存当前岗位”。
4. 插件会提取页面资料、保存当前可见区域截图，并打开岗位编辑页。
5. 核对公司、岗位和 JD；可以追加最多 5 张、单张不超过 5 MB 的本机截图。

### 3. 生成定制简历提示词

1. 在岗位档案中打开目标岗位。
2. 确保已有母版简历，公司和岗位已填写，并且至少有 JD 文本或岗位截图。
3. 点击“生成提示词”，再点击“复制提示词”。
4. 把提示词、下载的母版文件和岗位截图一起发送给 Codex。
5. Codex 按提示词在用户配置的工作区 `output/<公司>_<岗位>/` 中生成 DOCX、PDF 和修改说明。

### 4. 填写网申表单

1. 进入企业网申表单页面，点击“简填”。
2. 查看网站支持程度、识别数量和填写预览。
3. 核对橙色字段后主动确认，点击“一键填写”。
4. 手动选择简历附件、逐项检查并自行提交。

## 安全与隐私边界

- 不自动提交申请，不处理验证码，不绕过登录或网站限制。
- 不调用 AI API，不上传母版、岗位资料或截图。
- 不填写密码、银行卡、社保、公积金、法律声明、背景调查和竞业授权。
- 只在用户点击扩展时获得当前页面的临时权限。
- “清除全部本机资料”会删除基本资料、母版、岗位档案和截图。

详细说明见 [PRIVACY.md](./PRIVACY.md)。
